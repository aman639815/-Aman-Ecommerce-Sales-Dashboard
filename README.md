📊 Aman Ecommerce Sales Dashboard

An interactive E-Commerce Sales Dashboard built in Microsoft Power BI to analyze online sales performance, profit, quantity, customers, categories, payment modes, states, and monthly trends.

📌 Project Overview

This dashboard provides a clear and interactive view of e-commerce sales data. It helps users understand overall business performance and identify trends across different dimensions such as state, category, customer, payment mode, sub-category, and month.

📈 Key KPIs

The dashboard includes the following major performance indicators:

438K – Sum of Amount

6K – Sum of Quantity

37K – Sum of Profit

121K – Sum of AOV (Average Order Value)

📊 Dashboard Visualizations

The dashboard contains multiple interactive visuals:

Amount by State – Compares sales amount across different states.

Quantity by Category – Shows category-wise quantity distribution.

Profit by Month – Displays monthly profit trends.

Amount by Customer – Compares sales amount generated by customers.

Quantity by Payment Mode – Analyzes quantity based on payment methods.

Profit by Sub-Category – Shows profit contribution from different product sub-categories.

Quarter Filter – Allows users to analyze performance by quarter.

Category/Selection Filter – Provides interactive filtering for deeper analysis.
